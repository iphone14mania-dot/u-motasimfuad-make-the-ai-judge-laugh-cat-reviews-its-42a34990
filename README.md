A tiny Node program that writes one funny single-line one-star review from a house cat about its human to `/output/entry.txt`. The complaint is the moving sunbeam — a different spot every day, no notice, no apology — and the sting lands in the last few words: the cat filed the review from the new sunbeam. 136 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
